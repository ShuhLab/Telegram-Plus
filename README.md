# Telegram+ by Shuh Lab

Telegram+ helps teams handle incoming Telegram Business messages. The assistant follows the team's instructions and can hand a conversation to a person. Pilot access is arranged individually through Shuh Lab.

[Request pilot access](https://m2g.pro/store/telegram-plus/en/#access) · [Доступ к пилоту](https://m2g.pro/store/telegram-plus/#access)

**Try it with a colleague.** Pick one test conversation and give the assistant a short rule, for example “We open at 10. Ask the manager about discounts.” Ask when the shop opens, then ask for a discount. Check that the first answer follows your rule and the second question reaches a person.

[Report a problem or suggest an improvement](https://github.com/ShuhLab/Telegram-Plus/issues/new). Include your interface language, steps, expected result and actual result. Use fictional examples. GitHub issues are public.

Чтобы запросить доступ, откройте страницу пилота и укажите, какой сценарий хотите проверить. Начните с одного тестового чата. Задайте правило «Мы открываемся в 10. Вопросы о скидках передавай менеджеру». Проверьте ответ на вопрос о времени открытия и передачу вопроса о скидке человеку.

Обратную связь можно оставить на русском в [Issues](https://github.com/ShuhLab/Telegram-Plus/issues). Опишите ожидаемый и фактический результат на вымышленном примере без личной переписки клиентов.
