# Test Telegram+ with a colleague

Ask which language the tester prefers. Pilot access is available by request at https://m2g.pro/store/telegram-plus/en/. This guide requires a separate Telegram+ connection to operate on a chat. Without that connection, walk through the example as a simulation and identify it as such.

1. Have the owner choose a test conversation with a consenting colleague. Check the connected account and that conversation's opt-in status using the available Telegram+ integration.
2. Ask the owner for one short support rule. Example: “We open at 10. Refer discount requests to a manager.”
3. Have the colleague ask about opening hours. Prepare a draft using the rule. Show the draft to the owner.
4. Have the colleague ask for a discount. Prepare a handoff containing the unresolved question and the minimum context the manager needs. Confirm the destination with the owner before sharing it.
5. Record whether the answer followed the rule and whether the handoff preserved the question. Submit feedback at https://github.com/ShuhLab/Telegram-Plus/issues using fictional dialogue.

Keep the exercise in draft mode. Access credentials and private transcripts do not belong in feedback.
